# Internationalization (i18n)

PARITY implements a custom lightweight i18n structure to maintain maximum performance and zero dependency overhead.

## Key Design Principles
- **No Third-Party Packages:** Avoid packages like `i18next` or `react-intl`.
- **Locale Files:** Located in `/i18n/{en,es,pt}/` and split into domain-specific modules:
  - `common`: Global UI buttons, labels, and shared terms.
  - `views`: Translations specific to views/screens.
  - `categories`: Names and descriptions of spending categories.
  - `alerts`: In-app warnings and alerts.
  - `fiscal`: Tax categories and reporting labels.
- **Languages Supported:**
  - `en` (English)
  - `es` (Spanish)
  - `pt` (Portuguese)

## How to use i18n translations

Translations are retrieved using the helper function `getTranslation`:

```typescript
import { getTranslation } from 'services/i18n';

// Usage example inside components
const label = getTranslation(userProfile.language, 'common.save');
```

### Fallback Chain:
1. Target key under the selected language (e.g., `es`).
2. Target key under default language `en` (English).
3. Plain key name string if not found anywhere else.
